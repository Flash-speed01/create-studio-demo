# CreateShop

CreateShop is a lightweight, browser-based graphic design editor for making simple graphics with text and shapes.

## Run it

Open `index.html` in a modern browser. No build step or installation is required.

## Features

- Add text, rectangles, and circles to an 800 × 520 canvas.
- Drag elements to arrange your design.
- Edit text, colors, outlines, font size, and shape dimensions.
- Select elements from the layers list or directly on the canvas.
- Export a crisp 2× PNG.
- Designs are saved automatically in local browser storage.

## Files

- `index.html` — app layout and page metadata
- `styles.css` — responsive editor styling
- `app.js` — canvas interaction, properties, local saving, and PNG export

The editor uses vanilla JavaScript and SVG, with no build tooling required.
